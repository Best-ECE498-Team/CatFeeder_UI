# PawPlate App

PawPlate is a mobile app designed to work alongside an automatic wet food feeder for cats. The app is being developed using React Native and Expo as part of a capstone project.

At this stage, the app is still in its early development phase. The main goal right now is to set up the basic app structure, navigation, and visual design before adding hardware communication and feeder control features.

## Project Overview

The PawPlate system is intended to help users monitor and manage an automatic wet food feeder. The final system will include a feeder device with rotating bowls, a camera-based food detection system, and a mobile app interface.

The app will eventually allow users to view bowl status, check feeding schedules, adjust settings, and receive information from the feeder system.

## Current App Features

The current version of the app includes:

- Basic Expo React Native setup
- Bottom tab navigation
- Home screen
- Bowl screen
- Schedule screen
- Settings screen
- PawPlate loading/splash screen design
- Placeholder UI for future feeder features

## Planned Features

Future versions of the app may include:

- Displaying food status for each bowl
- Showing whether a bowl is full, partially full, empty, or unknown
- Feeding schedule setup
- Manual feeder controls
- Raspberry Pi connection settings
- Camera/food detection result display
- Notifications or alerts
- Backend/API communication with the feeder device
